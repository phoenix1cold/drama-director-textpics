## What is it?

Editor for **text + picture** overlays — the kind of "narrator card" you flash on screen between encounters. Mix multiple text and image layers in one preset, control position / scale / opacity / font / color / alignment per layer, save and reuse compositions. Apply delegates to `drama-director-cinematic` (install it for actual on-screen rendering).

Part of the [**Drama Director**](https://github.com/phoenix1cold/drama-director-hub) module family. Requires the **drama-director-hub** module — install it first.

---

## Install in Foundry VTT

1. First install the hub:
   ```
   https://github.com/phoenix1cold/drama-director-hub/releases/latest/download/module.json
   ```
2. Then this module — open **Add-on Modules** → **Install Module**, paste the **manifest URL**:
   ```
   https://github.com/phoenix1cold/drama-director-textpics/releases/latest/download/module.json
   ```
3. Click **Install**. Future updates: Foundry checks the same URL and offers an in-app update whenever a new release is published. The hub also surfaces a one-click update badge.

### Manual install (offline)

Download `module.zip` from the [latest release](https://github.com/phoenix1cold/drama-director-textpics/releases/latest) and extract it into your Foundry user-data folder at:

```
<FoundryUserData>/Data/modules/drama-director-textpics/
```

The extracted folder must contain `module.json` at its root.
